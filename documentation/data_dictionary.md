Data Dictionary
Overview

The cleaned sales dataset contains transaction-level information used for sales, customer, product, regional, channel, and profitability analysis.

The dataset is stored as:

data/cleaned/sales_cleaned.csv

Columns
Column	Description	Data Type	Business Meaning
Order_ID	Unique order identifier	Text	Identifies a customer order
Order_Item_ID	Unique order-line identifier	Text	Identifies an individual item within an order
Order_Date	Date the order was placed	Date	Used for time-based analysis
Customer_ID	Unique customer identifier	Text	Identifies the customer
Product_ID	Unique product identifier	Text	Identifies the product
Category	Product category	Text	Groups products for category analysis
Region	Sales region	Text	Identifies the geographic sales region
Sales_Channel	Sales channel	Text	Identifies Online or Retail sales
Quantity	Number of units sold	Integer	Measures sales volume
Discount	Discount applied to the transaction	Decimal	Measures the percentage discount
Unit_Cost	Cost per unit	Numeric	Represents the cost of one unit
List_Price	Product selling price before applicable discount	Numeric	Represents the listed selling price
Revenue	Revenue generated by the transaction	Numeric	Measures sales value
Cost	Total cost associated with the transaction	Numeric	Measures total product cost
Profit	Profit generated by the transaction	Numeric	Revenue minus cost
Profit_Margin	Profit as a percentage of revenue	Decimal	Measures transaction profitability
Derived Analysis Fields

Additional fields were created during analysis where required.

Discount_Band

Transactions were grouped into discount bands:

Discount Band	Definition
0%	No discount
1-10%	Discount greater than 0% and up to 10%
11-20%	Discount greater than 10% and up to 20%
21-30%	Discount greater than 20% and up to 30%
30%+	Discount greater than 30%, when present
Profit Margin

Profit margin is calculated as:

Profit / Revenue × 100

Loss Rate

Loss rate is calculated as:

Negative-profit transactions / Total transactions × 100

A transaction is classified as loss-making when:

Profit < 0

Data Preparation

The project follows this data flow:

Raw Dataset
    ↓
Data Cleaning
    ↓
Cleaned Dataset
    ↓
SQL Analysis
    ↓
Python Exploratory Analysis
    ↓
Business Findings


The raw dataset is preserved separately from the cleaned dataset so that the original source data remains available for reproducibility.

Data Quality Considerations

The cleaning process includes validation and preparation of fields required for analysis, including:

Date conversion
Data type validation
Missing-value checks
Duplicate checks
Numerical field validation
Business-rule validation
Preparation of analysis-ready fields

The SQL data-quality analysis provides additional validation of the dataset before analytical use.
